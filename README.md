# Party Map — releases

Finished builds of Party Map (WoW Forever addon and map app). No source here.

**Download the newest:** [PartyMap.zip](https://github.com/jordanlcreighton-commits/party-map-releases/raw/main/PartyMap.zip)

Unzip it and put the `PartyMap` folder into `World of Warcraft\_retail_\_forever_\Interface\AddOns`
(replace the old one), then start `PartyMap\App\PartyMap.exe`. After that the app keeps itself up to
date, and in game a small notice offers "Reload now" when there's a new version.

Version **0.16.3**, published 2026-11-20T23:20:05Z. 0.16.3: Where to level next? and Recommended quests test the side (Horde/Alliance) themselves: Questie's race test hides every Horde quest for some of Forever's races. Quest heading icons show their zone or dungeon on the map.

`manifest.json` lists the SHA-256 of the zip and of every file in it; the app checks them all before
it installs anything.
