# Party Map — releases

Finished builds of Party Map (WoW Forever addon and map app). No source here.

**Download the newest:** [PartyMap.zip](https://github.com/jordanlcreighton-commits/party-map-releases/raw/main/PartyMap.zip)

Unzip it and put the `PartyMap` folder into `World of Warcraft\_retail_\_forever_\Interface\AddOns`
(replace the old one), then start `PartyMap\App\PartyMap.exe`. After that the app keeps itself up to
date, and in game a small notice offers "Reload now" when there's a new version.

Version **0.16.6**, published 2026-11-21T19:56:23Z. Umberhide Skies 1.1.0: live weather by zone, storms that roll in, lightning you can set (Party Map unchanged, 0.16.6).

`manifest.json` lists the SHA-256 of the zip and of every file in it; the app checks them all before
it installs anything.

**Bank Alt Helper** (a separate addon) is here too: [BankAltHelper.zip](https://github.com/jordanlcreighton-commits/party-map-releases/raw/main/BankAltHelper.zip), version
**0.6.3**. Put the `BankAltHelper` folder into the same AddOns folder once; after that Party Map's
app keeps it up to date as well. The app only ever updates it on a PC where it's already installed.

**Umberhide Skies** (weather and dark nights, a separate addon) is here too: [UmberhideSkies.zip](https://github.com/jordanlcreighton-commits/party-map-releases/raw/main/UmberhideSkies.zip),
version **1.1.0**. Put the `UmberhideSkies` folder into the same AddOns folder once and restart WoW;
after that Party Map's app keeps it up to date, again only on a PC where it's already installed.
